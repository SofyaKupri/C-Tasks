# Общая идея
Консольное приложение для учёта финансов пользователей Ф-Банка.

Умеет
# Приципы DDD
Rich Domain Model: Account самостоятельно управляет своим балансом и хранит данные об аккаунте.

Изоляция домена: Accout, Operation, Category не связаны с работой консили.
# Патерны GoF
Фабрика: Factory централизованно создаёт объекты

Фасад: AccountFacade скрывает логику пополнения/списывания

Команда: Command делает каждое действия объектом

Декоратор: TimerDecorator оборачивает любую команту, замеряет время её выполнения

Кэш: Cache ускоряет доступ к данным
